# scheduling-ethos
How to Use

Make an Excel file participants.xlsx with one column of participant names.
Example:

Name
Alice
Bob
Charlie
David
Eve
Frank
Grace
Helen


Run the script.

It will create contest_schedule.xlsx with a schedule like:

Time	Team 1	Team 2
10:00	Alice, Bob	Charlie, David
10:30	Eve, Frank	Grace, Helen
